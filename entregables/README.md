# Entregables y materiales co-creados

Este directorio registra los materiales académicos y documentales producidos conjuntamente dentro del proyecto **FINANZAS A LARGO PLAZO — Grupo 80 — 2026.2**.

## Política

- Los materiales creados en el proyecto deben quedar incorporados a GitHub y versionados cuando corresponda.
- Las fuentes externas grandes o protegidas por derechos de autor se referencian en `docs/FUENTES.md` y no necesitan copiarse al repositorio.
- Por defecto, los documentos de entrega se generan en Word; el PDF se produce únicamente a pedido expreso.
- Siempre que sea práctico, se conservará además una representación editable o reproducible del material para no depender exclusivamente de archivos binarios o del historial del chat.
- Ningún entregable público debe incluir datos personales o sensibles de estudiantes.
