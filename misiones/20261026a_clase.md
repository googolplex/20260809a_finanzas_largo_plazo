**Corrección:** añadir, inmediatamente después de la tabla de escenarios con probabilidades por fila y TOTAL 100 %, la expresión `E(R) = Σ pᵢ Rᵢ`, su significado y el cálculo completo, activo por activo:
- ALFA: `0,25×16 % + 0,25×8 % + 0,25×(−4 %) + 0,25×12 % = 4 % + 2 % − 1 % + 3 % = 8 %`.
- BETA: `0,25×2 % + 0,25×10 % + 0,25×14 % + 0,25×6 % = 0,5 % + 2,5 % + 3,5 % + 1,5 % = 8 %`.

**Interpretación:** el mismo rendimiento esperado no implica igual riesgo ni resultado garantizado; los cuatro escenarios son una suposición didáctica equiprobable, de modo que en este caso el promedio ponderado coincide con el promedio aritmético. Se conservan la tabla 25 % × 4 = 100 %, el caso ALFA/BETA y los resultados de riesgo existentes. La versión v4 organiza la explicación en dos páginas para facilitar lectura, manteniendo el contenido didáctico.

Se calculan **momentos poblacionales** `σ² = Σ p_i(R_i - E(R))²`, sin usar corrección muestral `n-1`.
