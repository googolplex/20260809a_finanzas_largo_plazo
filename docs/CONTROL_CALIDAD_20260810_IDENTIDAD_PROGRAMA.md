## Consecuencia sobre ICA-035 y la transversalidad

`ICA-035` debe tratarse como un código histórico o perteneciente a otra instancia curricular hasta que una fuente institucional vigente demuestre lo contrario. No debe presentarse como código actual del Grupo 80.

La presencia de una asignatura denominada **Finanzas a Largo Plazo** en varias carreras no prueba que el Grupo 80 sea administrativamente una asignatura **homóloga** o **transversal**. En consecuencia, esas expresiones se eliminan de los materiales actuales salvo que aparezca una fuente institucional explícita que las confirme para este grupo.
