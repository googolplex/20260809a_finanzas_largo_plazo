## Consecuencia sobre ICA-035 y la transversalidad

`ICA-035` debe tratarse como un código histórico o perteneciente a otra instancia curricular. No debe presentarse como código actual del Grupo 80.

En consecuencia, esas expresiones no deben utilizarse para el grupo actual salvo que exista una fuente institucional explícita que las confirme.
