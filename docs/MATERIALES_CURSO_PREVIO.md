# Materiales del curso previo

Este documento registra los materiales de un curso anterior aportados como antecedentes para el proyecto **FINANZAS A LARGO PLAZO — 2026.2**. Su función es conservar procedencia, evitar duplicados y facilitar la comparación posterior con los materiales propios preparados por el docente.

## Criterio de uso

Estos documentos se consideran **antecedentes didácticos y de estudio**, no normativa institucional ni sustitutos del programa oficial. Los conceptos, fórmulas y ejemplos que se reutilicen en 2026 deberán contrastarse, cuando corresponda, con el programa vigente y con bibliografía académica identificable, especialmente Van Horne & Wachowicz y Brigham & Houston.

Los ejemplos con tasas tributarias, tasas de interés, tipos de cambio, empresas, sitios web o datos de mercado se consideran históricos/ilustrativos y no se asumirán vigentes.

## Observaciones para la comparación posterior

Cuando se incorporen los materiales propios preparados por el docente a partir de este curso, se mantendrán tres niveles separados:

1. **Fuente de base**: Montesinos (2006) y otros textos explícitamente citados.
2. **Compilaciones/materiales del curso previo**: Justo Báez y materiales institucionales sin autoría personal explícita.
3. **Materiales propios del docente**: se registrarán con su autoría y fecha cuando sean aportados, indicando que fueron elaborados a partir de estudios previos y fuentes identificadas cuando corresponda.

No se atribuirá al material propio una autoría ajena, ni se presentará una compilación como fuente original de una fórmula o teoría cuando el propio documento identifique una fuente anterior.
